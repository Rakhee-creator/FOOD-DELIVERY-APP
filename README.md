Food Delivery Application
A simple Java console-based Food Delivery Application developed while learning Object-Oriented Programming (OOPS) concepts.

Project Overview
This project simulates a basic food delivery workflow where:
-Customers place orders
-Restaurants provide menu items
-Orders contain selected food items
-Payments are processed using different payment methods
-Delivery partners deliver the order

Technologies Used
-Java
-OOPS Concepts
-ArrayList
-Interfaces
-Polymorphism
-Encapsulation
